# Kola

A grandparent records a phrase in her own voice. The grandchild hears it and records a reply. She hears the reply and taps Yes or Again. Each Yes adds the word to the child's wall.

Built for the Devpost "Build With AI: Basics" hackathon. Planning documents are in `devpost/`.

Status: planning (start, scope, PRD, spec), build not started.
